## Part 3 — Validation steps

**How I validated the output:**

For each task, I ran the cell myself after Claude Code wrote it and checked the actual printed output against what the task instructions and in-cell comments said to expect, rather than assuming the code was correct because it ran without error, because it could have ran something incorrect with no errors. Also after each task cell, I asked for a line by line explanation before moving on, so I could better understand the code instead of just knowing it worked, this also helped in the write ups. 

**Something the AI got wrong that I corrected:**

This is not something it got wrong but an important thing to note. Anthropic released a new model (Opus 5.5) recently and the now default model is Opus 5.5, however this takes much more usage than Sonnet which is a model plenty strong to do the coding for these assignments. It is just important to make sure to check the model, and think about what the task you are going to have it do, if I let Opus 5.5 be the model I would run out of usage much quicker, for a small assignment like this it may not matter, but for bigger projects it would.
